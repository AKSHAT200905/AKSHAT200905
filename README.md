### 🚀 Featured Projects

#### 1. TradeRecon — Trade Reconciliation Platform

`Python` `FastAPI` `React` `PostgreSQL` `Docker` `CI/CD`

- Built a microservices platform to reconcile trades between an internal trading desk and a custodian bank, detecting **9 break types** and calculating dollar exposure.
- Developed two FastAPI services with separate PostgreSQL databases and REST communication.
- Created a React dashboard for CSV ingestion, validation, break resolution, audit trails, KPIs, and exports.
- Added **43 automated tests** and a Docker Compose-based CI/CD pipeline.

#### 2. CamoVision X — Camouflaged Threat Detection

`Python` `PyTorch` `YOLOv8m` `SINet-V2` `ONNX`

- Developed an object detection and segmentation pipeline for detecting camouflaged soldiers and weapons.
- Trained a unified YOLOv8m detector achieving **86.3% mAP@0.5**, with 91.4% precision and 80.3% recall.
- Fine-tuned SINet-V2 for pixel-level camouflage segmentation, achieving an MAE of **0.0177**.
- Implemented confidence fusion and exported the pipeline to ONNX for inference consistency.

#### 3. Smart Traffic Violation Detection System

`Python` `YOLOv10m` `YOLOv8m` `ANPR`

- Developing a CCTV-based traffic enforcement system for Indian roads.
- Covers five violation types: red-light violations, wrong-side driving, triple riding, riding without a helmet, and overspeeding.
- Integrates automatic number plate recognition, appearance-based re-identification, and cryptographic evidence logging.
- Working in a two-member team using IISc's UVH-26 dataset.
